# Notes App

> ⚠️ **Project discontinued**

A full-stack notes application built while learning and practicing full-stack web development.

## Tech Stack

- React
- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Prisma
- Session-based authentication

## Features

- User registration and login
- Session-based authentication
- Create notes
- Delete notes
- User-specific notes
- React frontend communicating with an Express REST API
- PostgreSQL database with Prisma ORM

## Status

This project has been **discontinued**.

I decided to stop development before completing all planned features and move on to larger full-stack projects that are more relevant to my current portfolio goals.

The project is kept on GitHub as a record of my learning and development process.
